월세 수납 관리

월세 입금 확인과 임대료 수납 체크를 한 화면에서

매달 계좌 내역과 입금자명을 대조하는 일을 줄이세요. 랜디는 호실별 납입 상태, 수납률, 확인 필요 항목을 임대인이 바로 볼 수 있게 정리합니다.

반복되는 수납 확인 업무

누가 냈고, 누가 빠졌는지 바로 보여야 합니다

월세 수납 관리는 입금이 있었는지보다 어떤 호실의 어떤 세입자가 납입했는지를 빠르게 확인하는 일이 중요합니다. 랜디는 세입자, 호실, 월세, 납입일을 기준으로 매달 수납 상태를 정리합니다.

수납 현황 완납, 확인 필요, 미납 상태를 호실별로 구분합니다.
수납 이력 세입자별 납입 내역을 모아 반복 지연 여부를 확인합니다.
확인 흐름 은행 앱 확인 후 따로 표에 옮기는 업무를 줄이는 방향으로 설계합니다.

입금 알림 처리 방식

월세 납부 내역은 이렇게 기록합니다

자동화 범위와 데이터 처리 방식을 먼저 확인해 보세요.

랜디는 은행 계좌를 직접 연결하나요?

은행 계좌를 직접 연결하지 않습니다. Android 기기에 도착한 지원 은행 앱의 입금 알림을 분석하며, 은행 앱의 입금 알림과 랜디의 알림 접근 권한이 필요합니다. iOS에서는 납부 내역을 직접 등록합니다.

월세 납부 내역이 자동으로 기록되나요?

Android에서는 입금자·금액·납부월이 등록 정보와 일치하는 내역을 자동으로 기록합니다. 자동으로 연결되지 않는 입금이나 현금 납부는 내역을 확인한 뒤 직접 등록할 수 있습니다. 등록된 납부 내역은 앱에서 확인하고 수정할 수 있습니다.

입금자명이 다르면 어떻게 확인하나요?

입금자명이나 금액이 달라 자동으로 연결되지 않는 경우, 실제 입금 내역을 확인한 뒤 해당 호실에 납부 내역을 직접 등록해주세요.

월세 납부 후보를 한눈에 확인해 보세요

Google Play에서 랜디를 설치하고 입금 알림에서 정리된 납부 후보를 확인해 보세요.
