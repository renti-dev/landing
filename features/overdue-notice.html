월세 미납 안내

월세 미납 안내를
간편하게 준비하세요

미납 호실을 확인하고, 저장한 안내 문구로 세입자에게 연락하세요. 내용 확인과 발송은 기기의 기본 문자 앱에서 직접 진행합니다.

안내 문구 관리

자주 쓰는 문구를
저장해두세요

매달 쓰는 월세 안내 문구를 템플릿으로 저장하세요. 다음 안내 때 다시 선택하거나, 상황에 맞게 직접 작성할 수 있습니다.

문구 저장 자주 쓰는 안내에 이름을 붙여 템플릿으로 저장합니다.
문구 수정 안내 내용이 달라지면 저장한 템플릿을 수정합니다.
직접 작성 저장된 문구가 없을 때는 새 안내 내용을 직접 작성합니다.

문자 안내 순서

문구 선택부터 발송까지

수납 현황에서 미납 호실을 확인한 뒤, 안내 문구와 수신자를 선택하세요.

  1. 안내 문구 선택

    저장한 템플릿을 고르거나 보낼 내용을 직접 작성합니다.

  2. 수신자 선택

    안내할 세입자를 선택하고 연락처와 내용을 확인합니다.

  3. 문자 앱에서 발송

    기본 문자 앱이 열리면 수신자와 내용을 검토한 뒤 직접 발송합니다.

문자 통신요금은 이용 중인 통신사 요금제에 따라 부과될 수 있습니다.
