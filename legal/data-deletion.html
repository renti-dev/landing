계정 및 사용자 데이터 삭제 안내

이공일소프트 팀이 제작한 랜디(Landy)는 앱 내에서 계정 및 사용자 데이터 삭제를 지원합니다. 본 안내는 계정 삭제 방법과 삭제되는 데이터 항목, 보관 기준을 설명합니다.

1. 앱 내 계정 삭제 방법

랜디 앱에 로그인한 후 아래 절차에 따라 계정 삭제를 요청할 수 있습니다.

  1. 설정 탭으로 이동합니다.
  2. 계정 관리 섹션의 회원 탈퇴 버튼을 선택합니다.
  3. 안내 내용을 확인한 뒤 확인 버튼을 누르면 회원 탈퇴가 완료됩니다.
  4. 회원 탈퇴가 완료되면 사용자 계정 및 해당 계정과 연결된 개인정보는 삭제됩니다.

2. 이메일을 통한 계정 및 데이터 삭제 요청

앱에 로그인할 수 없거나, 기타 방법으로 계정 및 사용자 데이터 삭제를 요청하고자 하는 경우 아래 이메일로 요청하실 수 있습니다.

  • 요청 이메일: support.landy@gmail.com
  • 이메일 제목: 랜디 계정 및 데이터 삭제 요청
  • 이메일 내용: 가입에 사용한 소셜 로그인 종류(Kakao 또는 Google), 닉네임, 삭제 요청 내용

요청 접수 후 필요한 경우 본인 확인 절차를 거칠 수 있으며, 본인 확인이 완료되면 관련 법령에 따라 지체 없이 계정 및 사용자 데이터를 삭제합니다. 삭제 처리가 완료되면 요청하신 이메일로 처리 완료 사실을 안내드립니다.

3. 삭제되는 데이터 항목 및 보관 기간

회원 탈퇴 또는 삭제 요청 시 삭제되는 데이터는 다음과 같습니다.

데이터 유형 세부 항목 삭제 또는 보관 기준
사용자 계정 정보 이메일 주소, 소셜 로그인 식별자 삭제 요청 처리 완료 시 지체 없이 삭제
사용자 프로필 정보 닉네임, 프로필 설정 정보 삭제 요청 처리 완료 시 지체 없이 삭제
임대 관리 데이터 사용자가 직접 등록한 매물, 호실, 계약, 월세 수납 기록, 일정 정보 삭제 요청 처리 완료 시 지체 없이 삭제
계약서 데이터 업로드한 임대차계약서 이미지, 계약서에서 추출된 계약 정보 추출 정보는 삭제 요청 처리 완료 시 지체 없이 삭제, 원본 이미지는 업로드 후 7일 경과 시 자동 삭제
알림 및 문의 기록 앱 내 알림 설정, 문의 또는 요청 기록 삭제 요청 처리 완료 시 지체 없이 삭제
운영·보안 로그 접속 IP, 접속 일시, 요청 경로, 오류 로그 보안 사고 대응 및 장애 분석을 위해 생성일로부터 3개월간 보관 후 파기

서버에 저장된 계정·임대관리·납부 데이터는 삭제 요청 처리 완료 시 지체 없이 삭제됩니다. 다만, 운영·보안 로그는 위 표와 같이 생성일로부터 3개월간 보관된 뒤 파기되며, 관계 법령에 따라 별도 보관이 필요한 정보가 있는 경우 해당 법령에서 정한 기간 동안 분리하여 보관한 뒤 파기합니다.

4. 유의사항

계정 삭제가 완료되면 삭제된 데이터는 복구할 수 없습니다.

계정 삭제 후에도 앱을 다시 이용하려면 새 계정으로 가입해야 합니다.

기기 내에 저장되는 은행 입금 알림 후보 정보는 서버 데이터가 아니므로 회원 탈퇴와 별개로 앱 삭제 또는 앱 데이터 삭제 시 기기에서 제거됩니다.
